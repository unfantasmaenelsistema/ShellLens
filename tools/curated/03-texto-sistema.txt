# Búsqueda de texto, procesos, usuarios y sistema

@@ grep egrep fgrep rgrep
es: busca líneas que coinciden con un patrón (texto o expresión regular)
tags: read
pos: PATRÓN?unless=-e,-f,--regexp,--file | Lo que se busca: texto o expresión regular. Si tiene espacios o símbolos, ponlo entre comillas. || What to search for: text or regular expression. If it contains spaces or symbols, quote it.
pos: ARCHIVO... | Archivo(s) donde buscar. Sin archivos lee la entrada estándar (con -r, el directorio actual). || File(s) to search. With none reads standard input (with -r, the current directory).
-i --ignore-case | No distingue mayúsculas de minúsculas. || Ignore case distinctions.
-v --invert-match | Invierte: muestra las líneas que NO coinciden. || Invert the sense of matching: show non-matching lines.
-r --recursive | Busca recursivamente en un directorio (sin seguir enlaces simbólicos). || Read all files under each directory, recursively (without following symlinks).
-R --dereference-recursive | Como -r pero siguiendo enlaces simbólicos. || Like -r but following all symlinks.
-n --line-number | Muestra el número de línea de cada coincidencia. || Prefix each line of output with its line number.
-l --files-with-matches | Muestra solo los nombres de archivo que contienen coincidencias. || Print only the names of files containing matches.
-L --files-without-match | Muestra los archivos SIN coincidencias. || Print the names of files with no matches.
-c --count | Cuenta las líneas que coinciden en vez de mostrarlas. || Print a count of matching lines.
-o --only-matching | Muestra solo la parte que coincide, no toda la línea. || Print only the matched parts of a line.
-w --word-regexp | La coincidencia debe ser una palabra completa. || Match only whole words.
-x --line-regexp | La coincidencia debe ocupar la línea entera. || Match only whole lines.
-E --extended-regexp | Expresiones regulares extendidas (permiten + ? | () {} sin barra invertida). || Extended regular expressions (allow + ? | () {} without backslash).
-F --fixed-strings | Busca texto literal, sin interpretar caracteres especiales (más rápido). || Search literal text, no special characters (faster).
-P --perl-regexp | Expresiones regulares estilo Perl (\d, \w, lookahead…). || Perl-style regular expressions (\d, \w, lookahead…).
-e --regexp=PATRÓN | Usa PATRÓN como patrón; sirve para varios patrones o uno que empiece por «-». || Use PATTERN as pattern; for several patterns or one starting with "-".
-f --file=ARCHIVO | Lee los patrones de un archivo, uno por línea. || Take patterns from a file, one per line.
-A --after-context=NUM | Muestra NUM líneas DESPUÉS de cada coincidencia. || Print NUM lines of trailing context.
-B --before-context=NUM | Muestra NUM líneas ANTES de cada coincidencia. || Print NUM lines of leading context.
-C --context=NUM | Muestra NUM líneas antes y después. || Print NUM lines of output context.
-h --no-filename | No muestra el nombre del archivo en cada línea. || Suppress the prefixing of file names on output.
-H --with-filename | Muestra siempre el nombre del archivo. || Print the file name for each match.
-s --no-messages | Suprime los errores de archivos inexistentes o ilegibles. || Suppress error messages about nonexistent or unreadable files.
-q --quiet --silent | No escribe nada: solo el código de salida (0 = hubo coincidencia). || Quiet: write nothing, exit with 0 if a match was found.
-m --max-count=NUM | Se detiene tras NUM líneas coincidentes. || Stop reading a file after NUM matching lines.
-a --text | Trata los archivos binarios como texto. || Process a binary file as if it were text.
-I | Ignora los archivos binarios. || Process a binary file as if it did not contain matching data.
--include=GLOB | Con -r, busca solo en archivos cuyo nombre coincida (p. ej. "*.log"). || With -r, search only files whose name matches (e.g. "*.log").
--exclude=GLOB | Con -r, omite los archivos que coincidan. || With -r, skip files whose name matches.
--exclude-dir=GLOB | Con -r, omite los directorios que coincidan. || With -r, skip directories that match.
--color=WHEN | Resalta las coincidencias (always, auto, never). || Surround the matched strings with colour markers.
-z --null-data | Las «líneas» terminan en byte nulo. || Treat input and output data as sequences of lines terminated by a zero byte.
tip: Comillas simples para el patrón: «grep 'a.*b'» evita que la shell interprete * ? $ antes que grep.

@@ sed
es: editor de flujo: transforma texto línea a línea (buscar y reemplazar, borrar, imprimir…)
tags: read write
special: sed
pos: GUION?unless=-e,-f,--expression,--file | Las órdenes de sed, normalmente entre comillas simples: s/viejo/nuevo/g, /patrón/d, 3,5p… || The sed commands, usually in single quotes: s/old/new/g, /pattern/d, 3,5p…
pos: ARCHIVO... | Archivo(s) a procesar (o la entrada estándar). || File(s) to process (or standard input).
-n --quiet --silent | No imprime cada línea automáticamente: solo lo que pidas con «p». || Suppress automatic printing of pattern space.
-e --expression=SCRIPT | Añade SCRIPT a las órdenes (se puede repetir). || Add the script to the commands to be executed.
-f --file=ARCHIVO | Lee las órdenes de un archivo. || Add the contents of the script file to the commands.
-i --in-place=SUFIJO | MODIFICA el archivo original; con SUFIJO (p. ej. -i.bak) guarda antes una copia. || EDIT the original file in place; with SUFFIX (e.g. -i.bak) a backup is kept.
-E -r --regexp-extended | Expresiones regulares extendidas (grupos () + ? | sin barra invertida). || Use extended regular expressions (groups () + ? | without backslash).
-s --separate | Trata cada archivo por separado (los números de línea reinician). || Consider files as separate rather than as a single continuous stream.
-z --null-data | Separa las líneas con byte nulo. || Separate lines by NUL characters.
-u --unbuffered | Sin búfer: lee y escribe lo mínimo. || Load minimal amounts of data and flush output more often.
--debug | Anota y explica el programa mientras se ejecuta. || Annotate program execution.
tip: Con -i sed edita el archivo sin preguntar: prueba antes sin -i o usa -i.bak.

@@ awk gawk mawk nawk
es: lenguaje de procesamiento de texto por campos y patrones
tags: read
pos: PROGRAMA?unless=-f,--file | El programa awk entre comillas simples: «patrón { acción }». Ej.: '{print $1}' imprime la primera columna. || The awk program in single quotes: "pattern { action }". E.g. '{print $1}' prints the first column.
pos: ARCHIVO... | Archivo(s) de entrada (o la entrada estándar). || Input file(s) (or standard input).
-F --field-separator=SEP | Separador de campos (por defecto, espacios y tabuladores). Ej.: -F: o -F',' . || Field separator (default: blanks). E.g. -F: or -F','.
-v --assign=VAR=VALOR | Define una variable antes de empezar. || Assign a variable before the program starts.
-f --file=ARCHIVO | Lee el programa de un archivo. || Read the program from a file.
tip: En awk, $1 es la primera columna, $NF la última, $0 la línea entera, NR el número de línea y NF el número de campos.

@@ sudo
es: ejecuta un comando con los privilegios de otro usuario (por defecto root)
en: execute a command as another user (root by default)
tags: priv exec
pos: COMANDO... | El comando (y sus argumentos) que se ejecutará con privilegios. || The command (and its arguments) to run with privileges.
-u --user=USUARIO | Ejecuta como ese usuario en vez de root. || Run as that user instead of root.
-g --group=GRUPO | Ejecuta con ese grupo primario. || Run with that primary group.
-i --login | Abre una shell de login como el usuario destino (entorno completo, cambia al directorio personal). || Run a login shell as the target user (full environment, goes to their home).
-s --shell | Abre una shell como el usuario destino sin cambiar de directorio. || Run a shell as the target user without changing directory.
-E --preserve-env | Conserva las variables de entorno del usuario actual. || Preserve the user's environment.
-H --set-home | Pone HOME al directorio personal del usuario destino. || Set HOME to the target user's home directory.
-k --reset-timestamp | Invalida la contraseña recordada: la pedirá de nuevo. || Invalidate the cached credentials: ask for the password again.
-K --remove-timestamp | Elimina del todo la marca de tiempo de credenciales. || Remove the timestamp entirely.
-l --list | Lista qué comandos tienes permitidos con sudo. || List the allowed (and forbidden) commands for the user.
-v --validate | Renueva la autenticación sin ejecutar ningún comando. || Update the user's cached credentials, without running a command.
-b --background | Ejecuta el comando en segundo plano. || Run the command in the background.
-n --non-interactive | No pide contraseña: falla si hace falta. || Avoid prompting the user for input of any kind.
-S --stdin | Lee la contraseña de la entrada estándar (¡no la dejes en el historial!). || Write the prompt to standard error and read the password from standard input.
-e --edit | Edita archivos de forma segura (equivale a sudoedit). || Edit one or more files instead of running a command.
-A --askpass | Pide la contraseña con un programa gráfico externo. || Use a helper program for password prompting.
-p --prompt=PROMPT | Cambia el texto que pide la contraseña. || Use a custom password prompt.
-h --host=HOST | Ejecuta en el host indicado (con sudoers por host). || Run the command on a host other than the local one.

@@ su
es: cambia de usuario (por defecto a root) abriendo una shell
tags: priv exec
-l --login | Shell de login: entorno limpio y directorio personal del usuario destino (igual que escribir «su -»). || Login shell: clean environment and the target user's home (same as typing "su -").
-c --command=COMANDO | Ejecuta ese comando y vuelve, en lugar de abrir una shell interactiva. || Run that command and return, instead of an interactive shell.
-s --shell=SHELL | Usa esa shell en vez de la del usuario. || Run the specified shell instead of the user's default.

@@ ps
es: muestra los procesos en ejecución
tags: read
style: bsdfirst
~a | (estilo BSD) Procesos de todos los usuarios con terminal. || (BSD style) Processes of all users with a terminal.
~u | (estilo BSD) Formato orientado a usuario: usuario, %CPU, %MEM, inicio, comando. || (BSD style) User-oriented format: user, %CPU, %MEM, start, command.
~x | (estilo BSD) Incluye procesos SIN terminal (demonios, servicios). || (BSD style) Include processes WITHOUT a terminal (daemons, services).
~f | (estilo BSD) Muestra el árbol de procesos con ramas ASCII. || (BSD style) ASCII-art process tree.
-e -A | Todos los procesos del sistema. || Select all processes.
-f | Formato completo: UID, PID, PPID, hora de inicio y comando completo. || Full format: UID, PID, PPID, start time and the full command.
-F | Formato todavía más completo (incluye tamaño y CPU). || Extra full format (adds size and CPU).
-l | Formato largo. || Long format.
-u --user=USUARIO | Procesos de ese usuario. || Select by effective user ID or name.
-p --pid=PID | Solo ese proceso. || Select by process ID.
-C=NOMBRE | Procesos cuyo comando se llama así. || Select by command name.
-o --format=FORMATO | Elige las columnas: pid,ppid,user,%cpu,%mem,cmd… || User-defined format: choose the columns.
--forest | Árbol de procesos padre-hijo. || ASCII art process hierarchy.
--sort=CLAVE | Ordena por una columna (p. ej. -%mem para mayor memoria primero). || Specify sorting order (e.g. -%mem for biggest memory first).
-H | Muestra la jerarquía de procesos. || Show process hierarchy.
-T | Muestra los hilos de ejecución. || Show threads.
-w | Salida ancha (no recorta líneas). || Wide output.
tip: «ps aux» (BSD) y «ps -ef» (UNIX) listan todo; en la salida, PID = identificador, PPID = proceso padre, STAT = estado (R ejecutando, S dormido, Z zombi).

@@ kill
es: envía una señal a un proceso (por defecto TERM: pedirle que termine)
tags: system
special: kill
pos: PID... | Identificador(es) del proceso. «-1» = todos los procesos que puedas matar. || Process ID(s). "-1" = every process you can kill.
-l --list | Lista las señales disponibles. || List signal names.
-s --signal=SEÑAL | Señal a enviar, por nombre o número. || Specify the signal to be sent.
-9 | Señal KILL: muerte inmediata, el proceso no puede evitarla ni limpiar. || KILL signal: immediate death, the process cannot catch it or clean up.
-15 | Señal TERM: petición educada de terminar (la señal por defecto). || TERM signal: polite request to terminate (the default).
-1 | Señal HUP: recargar la configuración (en muchos demonios). || HUP signal: reload configuration (in many daemons).
-2 | Señal INT: igual que Ctrl+C. || INT signal: same as Ctrl+C.
-STOP | Pausa el proceso (no se puede ignorar). || Pause the process (cannot be ignored).
-CONT | Reanuda un proceso pausado. || Resume a paused process.
