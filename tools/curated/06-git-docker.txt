# Git, contenedores y orquestación

@@ git
es: sistema de control de versiones distribuido
tags: read write net
sub: add commit push pull clone checkout switch restore branch merge rebase log diff status stash reset revert tag remote fetch init show cherry-pick clean config blame bisect grep mv rm submodule worktree reflog describe shortlog apply format-patch archive gc fsck
subalias: ci=commit co=checkout br=branch st=status
-C=DIR | Ejecuta git como si se hubiera iniciado en DIR. || Run as if git was started in DIR.
-c=CLAVE=VALOR | Fija una opción de configuración solo para este comando. || Pass a configuration parameter for this command only.
--no-pager | No usa paginador. || Do not pipe Git output into a pager.
--version | Muestra la versión. || Show the version.
-p --paginate | Usa paginador. || Pipe all output into less.
--git-dir=RUTA | Ruta del repositorio (.git). || Set the path to the repository.
--work-tree=RUTA | Ruta del árbol de trabajo. || Set the path to the working tree.
--exec-path[=RUTA] | Muestra o fija la ruta de los programas de git. || Path to wherever your core Git programs are installed.

@@ git-init
es: crea un repositorio de git vacío en el directorio actual
tags: write
-b --initial-branch=NOMBRE | Nombre de la rama inicial (p. ej. main). || Use the specified name for the initial branch.
--bare | Crea un repositorio «desnudo» (sin árbol de trabajo, para servidores). || Create a bare repository.

@@ git-clone
es: copia un repositorio remoto a un directorio nuevo
tags: net write
pos: URL | Repositorio a clonar (https://…, git@host:usuario/repo.git). || Repository to clone (https://…, git@host:user/repo.git).
pos: DIRECTORIO? | Carpeta de destino (por defecto, el nombre del repo). || Destination folder (default: the repo name).
--depth=N | Clon superficial: solo los últimos N commits (más rápido y pequeño). || Shallow clone: only the last N commits (faster, smaller).
-b --branch=RAMA | Clona esa rama (o etiqueta) en vez de la principal. || Clone that branch (or tag) instead of the default.
--recursive --recurse-submodules | Clona también los submódulos. || Also clone submodules.
--single-branch | Clona solo una rama. || Clone only the history leading to a single branch.
--mirror | Réplica exacta (todas las referencias). || Set up a mirror of the source repository.
-o --origin=NOMBRE | Nombre del remoto (por defecto origin). || Instead of using origin as the name of the remote, use NAME.
--bare | Repositorio desnudo. || Make a bare Git repository.

@@ git-status
es: muestra el estado del árbol de trabajo (cambios, archivos sin seguimiento)
tags: read
-s --short | Salida resumida. || Give the output in the short-format.
-b --branch | Muestra también la rama. || Show the branch and tracking info.
--ignored | Muestra también los ignorados. || Show ignored files as well.

@@ git-add
es: añade cambios al área de preparación (stage) para el próximo commit
tags: write
pos: RUTA... | Archivos o carpetas a preparar; «.» = todo lo del directorio actual. || Files or folders to stage; "." = everything in the current directory.
-A --all | Prepara todo: nuevos, modificados y borrados de todo el repositorio. || Stage everything: new, modified and deleted across the whole repo.
-p --patch | Elige interactivamente qué trozos (hunks) preparar. || Interactively choose hunks to stage.
-u --update | Prepara solo los ya seguidos (modificados y borrados). || Stage only already-tracked files (modified and deleted).
-n --dry-run | Simula. || Don't actually add the files, just show if they exist.
-f --force | Permite añadir archivos ignorados. || Allow adding otherwise ignored files.
-N --intent-to-add | Registra la intención de añadir un archivo nuevo. || Record only the fact that the path will be added later.
-v --verbose | Detallado. || Be verbose.

@@ git-commit
es: guarda los cambios preparados como un commit en el historial
tags: write
-m --message=MENSAJE | Mensaje del commit (sin esta opción se abre el editor). || Commit message (without it the editor opens).
-a --all | Prepara automáticamente todo lo modificado y borrado (no los archivos nuevos) antes de confirmar. || Automatically stage everything modified and deleted (not new files) before committing.
--amend | REESCRIBE el último commit (cambia mensaje o contenido). No lo hagas si ya está publicado. || REWRITE the last commit (message or content). Don't do it if already pushed.
--no-edit | Con --amend, mantiene el mensaje. || With --amend, keep the message.
-v --verbose | Muestra el diff en el editor del mensaje. || Show unified diff in the commit message editor.
-s --signoff | Añade la línea «Signed-off-by». || Add Signed-off-by trailer.
-S --gpg-sign[=ID] | Firma el commit con GPG. || GPG-sign commits.
--no-verify -n | Se salta los hooks (pre-commit, commit-msg). || Bypass the pre-commit and commit-msg hooks.
--allow-empty | Permite un commit sin cambios. || Allow creating a commit with no changes.
--author=AUTOR | Cambia el autor («Nombre <correo>»). || Override the commit author.
-F --file=ARCHIVO | Toma el mensaje de un archivo. || Take the commit message from the given file.
--fixup=COMMIT | Crea un commit «fixup» para un commit anterior (para rebase --autosquash). || Create a fixup commit for an earlier commit.
-e --edit | Edita el mensaje antes de confirmar. || Edit the message before committing.
-p --patch | Elige interactivamente los trozos. || Use the interactive patch selection interface.

@@ git-push
es: sube commits al repositorio remoto
tags: net write
pos: REMOTO? | Nombre del remoto (normalmente origin). || Name of the remote (usually origin).
pos: RAMA? | Rama (o referencia) a subir. || Branch (or ref) to push.
-u --set-upstream | Enlaza la rama local con la remota (así bastará «git push»/«git pull» después). || Link the local branch with the remote (so plain "git push"/"git pull" work afterwards).
-f --force | FUERZA la subida: sobrescribe la historia remota (puede borrar commits de otros). || FORCE the push: overwrites remote history (can erase others' commits).
--force-with-lease | Fuerza solo si nadie más ha subido cambios desde tu última descarga (más seguro que -f). || Force only if nobody else pushed since your last fetch (safer than -f).
--tags | Sube también todas las etiquetas. || All refs under refs/tags are pushed.
--delete -d | BORRA la rama o etiqueta remota. || DELETE the remote branch or tag.
--all | Sube todas las ramas. || Push all branches.
-n --dry-run | Simula. || Do everything except actually send the updates.
--no-verify | Se salta el hook pre-push. || Bypass the pre-push hook.
--follow-tags | Sube también las etiquetas anotadas de los commits subidos. || Push all the refs that would be pushed without this option, and also push annotated tags in refs/tags.
--prune | Borra las ramas remotas que no existan localmente. || Remove remote branches that don't have a local counterpart.

@@ git-pull
es: trae los cambios del remoto y los integra en tu rama (fetch + merge o rebase)
tags: net write
--rebase -r | Reaplica tus commits sobre lo descargado en lugar de crear un merge. || Reapply your commits on top of what was fetched instead of creating a merge.
--no-rebase | Fuerza el comportamiento de merge. || Force merge behaviour.
--ff-only | Solo avanza si puede hacerlo sin merge (falla si hay divergencia). || Only fast-forward; fail if the branches diverged.
--no-ff | Crea siempre un commit de merge. || Create a merge commit even when fast-forward is possible.
-p --prune | Elimina referencias remotas que ya no existen. || Remove any remote-tracking references that no longer exist on the remote.
--autostash | Guarda y recupera automáticamente los cambios locales. || Automatically create a temporary stash before the operation begins.
--tags | Descarga también todas las etiquetas. || Fetch all tags from the remote.

@@ git-fetch
es: descarga novedades del remoto sin tocar tu trabajo ni tus ramas locales
tags: net write
--all | Descarga de todos los remotos. || Fetch all remotes.
-p --prune | Elimina referencias remotas obsoletas. || Before fetching, remove any remote-tracking references that no longer exist on the remote.
--tags | Descarga todas las etiquetas. || Fetch all tags from the remote.
--depth=N | Limita la historia a N commits. || Limit fetching to the specified number of commits.

@@ git-checkout
es: cambia de rama o restaura archivos (orden antigua; hoy se prefiere switch y restore)
tags: write
-b=RAMA | Crea la rama nueva y se cambia a ella. || Create a new branch and switch to it.
-B=RAMA | Crea o REINICIA la rama indicada. || Create or reset the branch.
-f --force | Descarta los cambios locales al cambiar. || When switching branches, proceed even if the index or the working tree differs from HEAD.
--orphan=RAMA | Crea una rama sin historia. || Create a new orphan branch.
-t --track | Crea una rama que sigue a la remota. || Create a local branch tracking the remote one.
tip: «git checkout -- archivo» DESCARTA tus cambios en ese archivo sin posibilidad de recuperarlos. || "git checkout -- file" DISCARDS your changes to that file with no way to recover them.

@@ git-switch
es: cambia de rama
tags: write
-c --create=RAMA | Crea la rama y se cambia a ella. || Create a new branch named and switch to it.
-C --force-create=RAMA | Crea o reinicia la rama. || Similar to --create except that if the branch already exists, it is reset.
-d --detach | Se desconecta de las ramas (apunta a un commit). || Switch to a commit for inspection and discardable experiments.
-f --force | Descarta cambios locales. || Throw away local modifications.

@@ git-restore
es: restaura archivos del árbol de trabajo o del área de preparación
tags: write
-S --staged | Saca los archivos del área de preparación (no toca tu trabajo). || Unstage files (does not touch your work).
-W --worktree | Restaura el árbol de trabajo (descarta tus cambios). || Restore the working tree (discards your changes).
-s --source=COMMIT | Restaura desde ese commit. || Restore the working tree files with the content from the given tree.
-p --patch | Elige trozos interactivamente. || Interactively select hunks.

@@ git-branch
es: lista, crea o borra ramas
tags: write
-a --all | Lista ramas locales y remotas. || List both remote-tracking branches and local branches.
-r --remotes | Lista solo las remotas. || List or delete (if used with -d) the remote-tracking branches.
-d --delete | Borra una rama ya fusionada. || Delete a branch (only if fully merged).
-D | BORRA la rama aunque no esté fusionada (puedes perder commits). || DELETE the branch even if not merged (commits may be lost).
-m --move | Renombra una rama. || Move/rename a branch.
-v --verbose | Muestra el último commit de cada rama. || When in list mode, show sha1 and commit subject line for each head.
-u --set-upstream-to=REMOTA/RAMA | Fija la rama remota a seguir. || Set up tracking information.
--merged | Solo ramas ya fusionadas. || Only list branches whose tips are reachable from the specified commit.
--show-current | Muestra la rama actual. || Print the name of the current branch.

@@ git-merge
es: integra otra rama en la actual
tags: write
--no-ff | Crea siempre un commit de merge. || Create a merge commit even when the merge resolves as a fast-forward.
--ff-only | Solo avanza si es posible sin merge. || Refuse to merge unless the current HEAD is already up-to-date or the merge can be resolved as a fast-forward.
--squash | Junta todos los cambios en uno (sin crear el commit de merge). || Produce the working tree and index state as if a real merge happened, but do not make a commit.
--abort | Cancela un merge con conflictos y vuelve al estado anterior. || Abort the current conflict resolution process.
--continue | Termina el merge tras resolver conflictos. || After a merge stops due to conflicts you can conclude the merge.
-m --message=MENSAJE | Mensaje del commit de merge. || Set the commit message to be used for the merge commit.
-X=ESTRATEGIA | Opción de estrategia (ours, theirs). || Pass merge strategy specific option.

@@ git-rebase
es: reaplica tus commits sobre otra base (REESCRIBE la historia)
tags: write
-i --interactive | Modo interactivo: reordenar, unir (squash), editar o borrar commits. || Interactive mode: reorder, squash, edit or drop commits.
--onto=BASE | Traslada una serie de commits a otra base. || Starting point at which to create the new commits.
--continue | Continúa tras resolver un conflicto. || Restart the rebasing process after having resolved a merge conflict.
--abort | Cancela y vuelve al estado anterior. || Abort the rebase operation and reset HEAD to the original branch.
--skip | Salta el commit conflictivo. || Restart the rebasing process by skipping the current patch.
--autosquash | Aplica automáticamente los commits fixup. || Automatically squash commits with specially formatted messages.
--autostash | Guarda y recupera tus cambios locales. || Automatically create a temporary stash entry before the operation begins.
tip: No hagas rebase de commits que ya has publicado y otros han descargado. || Do not rebase commits you have already published and others have downloaded.

@@ git-log
es: muestra el historial de commits
tags: read
--oneline | Un commit por línea (hash corto y mensaje). || Shorthand for --pretty=oneline --abbrev-commit.
--graph | Dibuja el grafo de ramas. || Draw a text-based graphical representation of the commit history.
--all | Muestra todas las ramas. || Pretend as if all the refs in refs/ are listed on the command line.
-p --patch | Muestra los cambios de cada commit. || Generate patch.
-n --max-count=NUM | Limita a NUM commits (-5). || Limit the number of commits to output.
--author=PATRÓN | Solo commits de ese autor. || Limit the commits output to ones with author header lines that match the specified pattern.
--since --after=FECHA | Desde una fecha («2 weeks ago», 2025-01-01). || Show commits more recent than a specific date.
--until --before=FECHA | Hasta una fecha. || Show commits older than a specific date.
--grep=PATRÓN | Solo commits cuyo mensaje coincida. || Limit the commits output to ones with log message that matches the specified pattern.
--stat | Muestra qué archivos cambiaron y cuánto. || Generate a diffstat.
--name-only | Muestra solo los nombres de los archivos cambiados. || Show only names of changed files.
--follow | Sigue el historial de un archivo aunque se renombre. || Continue listing the history of a file beyond renames.
--pretty --format=FORMATO | Formato de salida (oneline, short, full, o personalizado). || Pretty-print the contents of the commit logs in a given format.
-S=TEXTO | Commits que añaden o quitan ese texto (la «piqueta» de git). || Look for differences that change the number of occurrences of the specified string.
--decorate | Muestra ramas y etiquetas junto a cada commit. || Print out the ref names of any commits that are shown.

@@ git-diff
es: muestra diferencias entre commits, ramas, el árbol de trabajo y el área de preparación
tags: read
--staged --cached | Diferencias de lo ya preparado (lo que se va a confirmar). || View the changes you staged for the next commit.

-U=N | Líneas de contexto. || Generate diffs with N lines of context.

@@ git-stash

tags: write

> list | Lista los stashes. || List stashes.
> drop | BORRA un stash. || DELETE a stash.
> clear | BORRA todos los stashes. || DELETE all stashes.
> show | Muestra el contenido de un stash. || Show a stash's content.
-u --include-untracked | Incluye también los archivos nuevos sin seguimiento. || Include untracked files.
-m --message=MENSAJE | Mensaje descriptivo. || Use the given message.

@@ git-reset
es: mueve la rama actual a otro commit (y opcionalmente cambia el área de preparación y tu trabajo)
tags: write
--soft | Mueve la rama; conserva todo preparado. || Move the branch; keep everything staged.
--mixed | Mueve la rama y vacía el área de preparación; conserva tus archivos (por defecto). || Move the branch and unstage; keep your files (default).
--hard | Mueve la rama Y DESCARTA todos los cambios del árbol de trabajo (irreversible). || Move the branch AND DISCARD all working tree changes (irreversible).
-p --patch | Elige trozos interactivamente. || Interactively select hunks.
tip: «git reset --hard» pierde cambios sin confirmar. Los commits «perdidos» suelen poder recuperarse con «git reflog». || "git reset --hard" loses uncommitted changes. "Lost" commits can usually be recovered with "git reflog".

-s --sign | Firma la etiqueta con GPG. || Make a GPG-signed tag.

> build | Construye una imagen a partir de un Dockerfile. || Build an image from a Dockerfile.
> ps | Lista contenedores (-a incluye los detenidos). || List containers (-a includes stopped ones).
> images | Lista las imágenes locales. || List local images.
> pull | Descarga una imagen. || Download an image.
> push | Sube una imagen a un registro. || Upload an image to a registry.
> exec | Ejecuta un comando dentro de un contenedor que ya está en marcha. || Run a command inside an already running container.
> logs | Muestra los registros de un contenedor. || Show a container's logs.
> stop | Detiene un contenedor (SIGTERM y luego SIGKILL). || Stop a container (SIGTERM then SIGKILL).
> start | Inicia un contenedor detenido. || Start a stopped container.
> restart | Reinicia un contenedor. || Restart a container.
> rm | BORRA contenedores (detenidos; con -f también en marcha). || REMOVE containers (stopped; with -f also running).
> rmi | BORRA imágenes. || REMOVE images.
> inspect | Muestra la información detallada en JSON. || Show detailed information as JSON.
> cp | Copia archivos entre el contenedor y el anfitrión. || Copy files between the container and the host.
> tag | Pone otra etiqueta a una imagen. || Tag an image.
> login | Inicia sesión en un registro (guarda credenciales en ~/.docker/config.json). || Log in to a registry (stores credentials in ~/.docker/config.json).
> logout | Cierra sesión en un registro. || Log out of a registry.
> compose | Gestiona aplicaciones de varios contenedores (docker-compose.yml). || Manage multi-container applications (docker-compose.yml).
> volume | Gestiona volúmenes (datos persistentes). || Manage volumes (persistent data).
> network | Gestiona redes de contenedores. || Manage container networks.
> system | Gestiona el sistema Docker (prune, df, info). || Manage Docker itself (prune, df, info).
> stats | Uso de recursos en vivo. || Live resource usage.
> top | Procesos de un contenedor. || Processes of a container.
> kill | Envía una señal a un contenedor. || Send a signal to a container.
> pause | Congela los procesos de un contenedor. || Freeze a container's processes.
> save | Guarda una imagen en un .tar. || Save an image to a .tar.
> load | Carga una imagen desde un .tar. || Load an image from a .tar.
> prune | Borra datos sin usar. || Remove unused data.
> info | Información del sistema Docker. || Docker system information.
> version | Versión de cliente y servidor. || Client and server version.
-H --host=SOCKET | Demonio al que conectar. || Daemon socket to connect to.
-v --version | Muestra la versión. || Print version.

@@ docker-run
es: crea un contenedor nuevo y ejecuta un comando en él
tags: exec net
pos: IMAGEN | Imagen de la que se crea el contenedor (nginx, ubuntu:22.04, usuario/app:1.0). || Image to create the container from (nginx, ubuntu:22.04, user/app:1.0).
pos: COMANDO... | Comando (y argumentos) a ejecutar dentro, en vez del que trae la imagen. || Command (and arguments) to run inside, instead of the image's default.
-d --detach | Segundo plano: no ocupa tu terminal. || Detached: does not occupy your terminal.
-i --interactive | Mantiene la entrada estándar abierta. || Keep STDIN open.
-t --tty | Asigna una terminal. || Allocate a pseudo-TTY.
--rm | Borra el contenedor automáticamente al terminar. || Automatically remove the container when it exits.
--name=NOMBRE | Nombre del contenedor. || Assign a name to the container.
